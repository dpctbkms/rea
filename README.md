# Rea Chart

트레이딩뷰(TradingView) 화면 구성과 사용 흐름을 참고해 다시 만든 웹 차트 앱입니다.
차트 렌더링에는 TradingView가 오픈소스(Apache-2.0)로 공개한
[lightweight-charts](https://github.com/tradingview/lightweight-charts)를 쓰고,
나머지(지표 계산, 툴바, 관심 목록, 그리기, 데이터 피드)는 직접 구현했습니다.
트레이딩뷰의 비공개 코드나 리소스는 쓰지 않았습니다.

## 기능

화면 구성과 조작 방식은 트레이딩뷰를 따랐습니다. 컴퓨터에서는 트레이딩뷰 웹, 휴대폰에서는 트레이딩뷰 앱처럼 보입니다.

- **휴대폰 앱 화면**: 아래 탭(관심 목록 · 차트 · 메뉴), 위 막대는 종목 · 타임프레임 하나 · 차트 종류 · 지표 · ⋯, 메뉴는 아래에서 올라오는 시트로 열립니다. 메뉴 탭에서 테마, 거래소, 차트 설정, 앱 설치, 정보를 봅니다.
- **앱다운 사용감**: 화면 전체가 확대되거나 튕기지 않고(두 손가락 확대는 차트만), 글자가 선택되지 않으며, 버튼을 누르면 바로 반응이 보입니다. 아래에서 올라온 창은 위쪽 손잡이를 끌어 내리거나 바깥을 눌러 닫습니다. 휴대폰을 가로로 돌리면 아래 탭이 왼쪽 세로 막대로 바뀌어 모든 화면을 가로로 쓸 수 있습니다. 그리기 점을 찍을 때 살짝 진동합니다(안드로이드).
- **십자선 + 버튼**: 트레이딩뷰처럼 십자선 높이의 가격 눈금 옆에 + 가 나옵니다(컴퓨터는 마우스를 올리면, 휴대폰은 차트를 길게 누르면). 누르면 그 가격에 **알림 추가 · 수평선 그리기 · 가격 복사**.
- **가격 알림**: 정한 가격 이상/이하가 되면 화면 위 알림, 진동, (허락하면) 휴대폰 알림. 차트에 주황 점선으로 보이고, 휴대폰은 메뉴, 컴퓨터는 오른쪽 종목 정보에서 지웁니다. 앱(또는 웹 페이지)이 열려 있는 동안만 확인합니다.
- **최신 봉으로**: 지난 봉을 보고 있으면 오른쪽 아래에 » 버튼이 나와 누르면 최신 봉으로 돌아갑니다.
- **관심 목록 편집**: 거래소마다 따로 저장됩니다. + 또는 검색 창의 별로 넣고, 휴대폰은 줄을 왼쪽으로 밀어 삭제, 컴퓨터는 줄에 마우스를 올려 ×로 뺍니다. 값이 바뀌면 초록·빨강으로 잠깐 반짝입니다.
- **앱으로 설치**: 홈 화면에 추가하면 주소창 없이 앱처럼 열리고, 인터넷이 끊겨도 화면은 켜집니다 (시세는 연결되면 다시 받음). 아이폰은 Safari 공유 버튼 → 홈 화면에 추가, 안드로이드는 Chrome ⋮ → 앱 설치.

- **위 툴바**: 종목 검색, 거래소, 즐겨찾기 타임프레임(▾ 목록에서 ★로 추가·제거), 차트 종류(바·캔들·속이 빈 캔들·하이킨아시·라인·영역·기준선), 지표, 실행 취소·다시 실행, 차트 설정, 전체 화면, 스크린샷, 테마
- **왼쪽 그리기 도구** (트레이딩뷰와 같은 묶음, 오른쪽 아래 삼각형 또는 같은 버튼 한 번 더 → 펼침 메뉴)
  - 커서: 십자선, 점, 화살표, 지우개
  - 추세선 도구: 추세선, 레이, 정보선, 확장선, 추세 각도, 수평선, 수평 레이, 수직선, 십자선, 평행 채널, 회귀 추세
  - 피보나치: 되돌림, 추세 기반 확장, 시간대 (기본 레벨 0~4.236, 레벨별 색)
  - 예측·측정: 롱·숏 포지션(한 번 클릭), 날짜 범위, 가격 범위, 날짜·가격 범위
  - 기하 도형: 브러시, 형광펜, 사각형, 원, 타원, 삼각형, 경로, 폴리라인
  - 주석: 텍스트(차트 위에서 바로 입력), 가격 라벨, 화살표, 위·아래 화살표 표시
  - 드로잉 모드 유지, 자석(약한·강한), 모두 잠그기, 모두 숨기기, 지우기(그림·지표·모두)
  - 그리기: 누른 채 끌었다 떼거나, 점마다 클릭. 경로·폴리라인은 마지막 점을 한 번 더 누르거나 Enter로 끝내기. `Esc`는 그리던 도형만 취소
  - **휴대폰에서 그려 둔 도형 다루기**: 탭하면 선택(손잡이와 떠 있는 막대), 선택된 도형은 끌어서 옮기고 손잡이를 끌면 그 점만 움직입니다(점을 지나는 십자선 표시). 선택 안 된 도형 위를 그냥 끌면 차트가 움직이고, 꾹 누르면(0.4초) 잡혀서 바로 옮길 수 있습니다. 누르다 손이 살짝 떨려도 도형은 밀리지 않습니다.
  - **휴대폰**: 트레이딩뷰 앱처럼 아래 연필 버튼으로 그리기 도구를 펼칩니다. 도구를 고르면 십자선이 바로 나타나고, 손가락을 끌면 십자선이 그만큼 움직이며, 탭하면 손가락 밑이 아닌 십자선 자리에 점을 찍습니다 (손가락이 점을 가리지 않음). 아래 안내에 몇 번째 점인지 나오고, 경로는 두 번 탭하면 끝납니다. 고른 도형의 막대에 45° 고정 버튼이 있습니다.
  - `Shift`+클릭: 도구 없이 바로 측정 (다음 클릭에 고정, 그다음 클릭에 사라짐)
  - `Shift`: 추세선·채널 0°·45°·90°, 사각형·타원은 정사각형·원, 몸통을 끌 때 가로·세로로만
  - 자석: 그리거나 점을 옮길 때 `Ctrl`(⌘)을 누르면 잠깐 반대로
  - 선택: 도형을 누르면 떠 있는 막대(손잡이로 끌어 옮기기·색·두께·모양·설정·잠금·삭제·더 보기: 복제·복사·맨 앞/맨 뒤로). `Ctrl`+클릭 여러 개 선택, `Ctrl`+끌기 복제, `Ctrl+C`/`Ctrl+V`, 오른쪽 클릭 메뉴
  - 설정 창(더블클릭): 스타일(연장·화살표·통계·피보나치 레벨), 텍스트, 좌표 직접 입력, 타임프레임별 보이기
  - 수평선·수직선 값과 선택한 도형의 점 좌표를 가격·시간 눈금에 표시. 도형은 시간·가격으로 저장돼 타임프레임을 바꿔도 같은 자리에 남습니다.
- **아래 막대**: 기간(1일·5일·1개월·3개월·6개월·연초 이후·1년·5년·전체, 알맞은 타임프레임으로 바꿔 보여 줌), 시계(시간대), 가격 눈금 `%`·`log`·`auto`
- **오른쪽 패널**: 관심 목록(현재가·변동·변동%)과 종목 정보(큰 현재가, 등락, 24시간 범위, 거래량). 오른쪽 끝 버튼으로 열고 닫습니다.
- **차트**: 가격 눈금에 봉 마감 카운트다운, 오른쪽 클릭 메뉴(차트 초기화, 이 가격에 수평선, 그림·지표 지우기, 설정), 차트 설정 창(캔들 색, 테두리, 현재가 선, 카운트다운, 배경, 격자, 상태 줄 표시)
- **단축키**: 글자 입력 → 종목 검색, 숫자 입력 후 Enter → 타임프레임(예: `15`, `4H`, `D`, `W`), `/` 지표, `Alt+R` 차트 초기화, `Alt+T` 추세선, `Alt+H` 수평선, `Alt+J` 수평 광선, `Alt+V` 수직선, `Alt+C` 십자선, `Alt+F` 피보나치, `Alt+Shift+R` 사각형, `Ctrl+Z`/`Ctrl+Y`, `Delete`, `Esc`
- **실시간 코인 시세 (무료, API 키 불필요)**: 업비트·빗썸(원화), 바이낸스·바이비트·OKX·비트겟·게이트(USDT), 코인베이스·크라켄(달러). 거래소마다 상장 종목 전체를 검색할 수 있습니다.
- **주식·환율·금·ETF**: Twelve Data 무료 API 키를 넣으면 볼 수 있습니다(분당 8회·하루 800회 한도라 2~5분마다 새로 고침). 키는 이 브라우저에만 저장됩니다.
- **지표 26종**: 이동평균(SMA·EMA·WMA·HMA·VWAP), 추세·채널(볼린저·켈트너·돈치안·엔벨로프·일목균형표·파라볼릭 SAR·슈퍼트렌드), 오실레이터(RSI·MACD·스토캐스틱·스토캐스틱 RSI·CCI·윌리엄스 %R·ADX/DMI·ROC·모멘텀), 변동성·거래량(ATR·거래량·OBV·MFI·CMF). 같은 지표를 여러 개 넣을 수 있고, 범례 줄에 마우스를 올리면(휴대폰은 누르면) 나오는 버튼으로 숨기기·설정·삭제합니다. 범례 아래 화살표로 지표 목록을 접습니다. 휴대폰에서는 트레이딩뷰처럼 길게 눌러 십자선을 띄웠을 때만 시가·고가·저가와 지표 값이 보입니다.
- 연결이 안 되면 자동으로 데모 데이터로 전환하고 상태 줄에 이유를 알려 줍니다. 설정은 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성
npm test           # 지표 계산 단위 테스트
node scripts/make-icons.cjs  # public/icons/*.svg를 고친 뒤 앱 아이콘 PNG 다시 만들기 (Playwright 필요)
npm run test:e2e   # 브라우저로 화면 동작 확인 (Playwright 필요)
```

`npm run build:artifact`는 앱을 웹 페이지 한 장(`dist-artifact/rea-chart.html`)으로 묶습니다. 이 버전은 데모 시세를 쓰고 스크린샷 버튼이 없습니다.

`?feed=demo`를 URL에 붙이면 네트워크 없이 데모 데이터로 실행합니다.

## GitHub Pages 배포

`.github/workflows/deploy.yml`이 기본 브랜치에 푸시될 때마다 테스트, 빌드, 배포를 실행합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 합니다.
배포 주소는 `https://<계정>.github.io/<저장소>/`입니다. Actions 탭에서 **Deploy to GitHub Pages → Run workflow**로 수동 배포도 할 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 차트 생성, UI 이벤트, 범례, 그리기, 관심 목록 |
| `src/feeds/` | 거래소별 시세 피드. 모두 같은 인터페이스를 가집니다(`common.js` 맨 위 설명 참고). |
| `scripts/check-feeds.mjs` | 거래소에 실제로 접속해 시세 연결을 점검합니다(`npm run check:feeds`). GitHub Actions의 **Check price feeds**로도 돌릴 수 있습니다. |
| `src/countdown.js` | 가격 눈금의 봉 마감 카운트다운 |
| `src/drawings.js` | 그리기 도구 (차트 확장 기능인 시리즈 프리미티브 하나에 모든 도형을 그림) |
| `src/studies.js` | 지표 목록과 설정 정의 (입력값, 선, 기준선). 새 지표는 여기에 추가합니다. |
| `src/indicators.js` | SMA, EMA, 볼린저, RSI(Wilder), MACD, VWAP, 하이킨아시 계산 |
| `test/` | 지표·피드 도우미 단위 테스트(`node --test`) |
| `e2e/` | 브라우저 확인 스크립트(`npm run test:e2e`) |
| `public/` | 앱 설치 파일: `manifest.webmanifest`, 오프라인용 `sw.js`, 아이콘(`icons/`) |
| `docs/PROGRESS.md` | 작업 기록: 진행 중, 완료, 해야 할 일. 작업마다 갱신 |

다른 거래소나 주식 데이터를 붙이려면 `src/feeds/`에 같은 인터페이스의 피드를 만들어 `src/feeds/index.js`의 `FEEDS`에 추가하면 됩니다.

사이트에는 `noindex` 표시가 있어 검색엔진 결과에 나오지 않습니다.
