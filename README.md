# Rea Chart

트레이딩뷰(TradingView) 화면 구성과 사용 흐름을 참고해 다시 만든 웹 차트 앱입니다.
차트 렌더링에는 TradingView가 오픈소스(Apache-2.0)로 공개한
[lightweight-charts](https://github.com/tradingview/lightweight-charts)를 쓰고,
나머지(지표 계산, 툴바, 관심 목록, 그리기, 데이터 피드)는 직접 구현했습니다.
트레이딩뷰의 비공개 코드나 리소스는 쓰지 않았습니다.

## 기능

화면 구성과 조작 방식은 트레이딩뷰를 따랐습니다.

- **위 툴바**: 종목 검색, 거래소, 즐겨찾기 타임프레임(▾ 목록에서 ★로 추가·제거), 차트 종류(바·캔들·속이 빈 캔들·하이킨아시·라인·영역·기준선), 지표, 실행 취소·다시 실행, 차트 설정, 전체 화면, 스크린샷, 테마
- **왼쪽 그리기 도구** (묶음별 펼침 메뉴, 오른쪽 아래 작은 삼각형 또는 같은 버튼 한 번 더)
  - 커서: 십자선, 점, 화살표
  - 선: 추세선, 연장선, 수평선, 수평 광선, 수직선, 십자선 / 평행 채널 / 피보나치 되돌림
  - 도형: 사각형, 타원 / 텍스트
  - 예측·측정: 롱 포지션, 숏 포지션(목표·손절·손익비), 가격·기간 측정
  - 자석, 그림 잠금, 그림 숨기기, 모두 지우기
  - 그린 도형은 눌러서 선택·이동하고, 손잡이를 끌어 모양을 바꿉니다. 시간·가격으로 저장돼 타임프레임을 바꿔도 같은 자리에 남습니다.
- **아래 막대**: 기간(1일·5일·1개월·3개월·6개월·연초 이후·1년·5년·전체, 알맞은 타임프레임으로 바꿔 보여 줌), 시계(시간대), 가격 눈금 `%`·`log`·`auto`
- **오른쪽 패널**: 관심 목록(현재가·변동·변동%)과 종목 정보(큰 현재가, 등락, 24시간 범위, 거래량). 오른쪽 끝 버튼으로 열고 닫습니다.
- **차트**: 가격 눈금에 봉 마감 카운트다운, 오른쪽 클릭 메뉴(차트 초기화, 이 가격에 수평선, 그림·지표 지우기, 설정), 차트 설정 창(캔들 색, 테두리, 현재가 선, 카운트다운, 배경, 격자, 상태 줄 표시)
- **단축키**: 글자 입력 → 종목 검색, 숫자 입력 후 Enter → 타임프레임(예: `15`, `4H`, `D`, `W`), `/` 지표, `Alt+R` 차트 초기화, `Alt+T` 추세선, `Alt+H` 수평선, `Alt+J` 수평 광선, `Alt+V` 수직선, `Alt+C` 십자선, `Alt+F` 피보나치, `Alt+Shift+R` 사각형, `Ctrl+Z`/`Ctrl+Y`, `Delete`, `Esc`
- **실시간 코인 시세 (무료, API 키 불필요)**: 업비트·빗썸(원화), 바이낸스·바이비트·OKX·비트겟·게이트(USDT), 코인베이스·크라켄(달러). 거래소마다 상장 종목 전체를 검색할 수 있습니다.
- **주식·환율·금·ETF**: Twelve Data 무료 API 키를 넣으면 볼 수 있습니다(분당 8회·하루 800회 한도라 2~5분마다 새로 고침). 키는 이 브라우저에만 저장됩니다.
- **지표 26종**: 이동평균(SMA·EMA·WMA·HMA·VWAP), 추세·채널(볼린저·켈트너·돈치안·엔벨로프·일목균형표·파라볼릭 SAR·슈퍼트렌드), 오실레이터(RSI·MACD·스토캐스틱·스토캐스틱 RSI·CCI·윌리엄스 %R·ADX/DMI·ROC·모멘텀), 변동성·거래량(ATR·거래량·OBV·MFI·CMF). 같은 지표를 여러 개 넣을 수 있고, 범례에서 숨기기·설정·삭제합니다.
- 연결이 안 되면 자동으로 데모 데이터로 전환하고 상태 줄에 이유를 알려 줍니다. 설정은 브라우저에 저장됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성
npm test           # 지표 계산 단위 테스트
```

`npm run build:artifact`는 앱을 웹 페이지 한 장(`dist-artifact/rea-chart.html`)으로 묶습니다. 이 버전은 데모 시세를 쓰고 스크린샷 버튼이 없습니다.

`?feed=demo`를 URL에 붙이면 네트워크 없이 데모 데이터로 실행합니다.

## GitHub Pages 배포

`.github/workflows/deploy.yml`이 기본 브랜치에 푸시될 때마다 테스트, 빌드, 배포를 실행합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 합니다.
배포 주소는 `https://<계정>.github.io/<저장소>/`입니다. Actions 탭에서 **Deploy to GitHub Pages → Run workflow**로 수동 배포도 할 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 차트 생성, UI 이벤트, 범례, 그리기, 관심 목록 |
| `src/feeds/` | 거래소별 시세 피드. 모두 같은 인터페이스를 가집니다(`common.js` 맨 위 설명 참고). |
| `scripts/check-feeds.mjs` | 거래소에 실제로 접속해 시세 연결을 점검합니다(`npm run check:feeds`). GitHub Actions의 **Check price feeds**로도 돌릴 수 있습니다. |
| `src/countdown.js` | 가격 눈금의 봉 마감 카운트다운 |
| `src/drawings.js` | 그리기 도구 (차트 확장 기능인 시리즈 프리미티브 하나에 모든 도형을 그림) |
| `src/studies.js` | 지표 목록과 설정 정의 (입력값, 선, 기준선). 새 지표는 여기에 추가합니다. |
| `src/indicators.js` | SMA, EMA, 볼린저, RSI(Wilder), MACD, VWAP, 하이킨아시 계산 |
| `test/` | 지표·피드 도우미 단위 테스트(`node --test`) |

다른 거래소나 주식 데이터를 붙이려면 `src/feeds/`에 같은 인터페이스의 피드를 만들어 `src/feeds/index.js`의 `FEEDS`에 추가하면 됩니다.

사이트에는 `noindex` 표시가 있어 검색엔진 결과에 나오지 않습니다.
